## Play the live interface

The [landing demo](/#try-it) has two modes. Automatic plays the existing film’s narration and music while updating the actual comparison and cart. Pause, mute, restart or seek through the 66-second tour. Captions use the same speech alignment as the film. “Follow actions on the page” keeps the current control in view; turn it off to scroll freely.

Choose **Take control**, switch to **Manual**, or use any demo control to stop playback and keep the current selection. Starting Automatic again resets the guided demo. The original video and all source audio remain available separately.

## Connect an MCP client

1. Switch the landing demo to **Manual**.
2. Expand **Connect your agent via MCP** and choose **Create MCP connection**.
3. Copy the generated configuration into a client that supports Streamable HTTP with a custom Authorization header. Configuration syntax varies by client: use the displayed URL as the server URL and the displayed Authorization value as the header.
4. Keep the browser tab open. Ask the agent to read the state, compare machines and change your selection.

No Fabrials account or API key is required for this fictional demo. The generated bearer token is a temporary capability for your tab only. Do not put it in a URL or share it publicly. **Disconnect agent** revokes it. Refreshing, leaving the page or switching to Automatic ends the connection.

Try: “Compare machines for a 40 cm counter and 54 mm accessories. Choose the compatible machine and open the selection for my review.”

## Available tools

- `get_coffee_state`: read constraints, comparison and the current cart.
- `compare_coffee_machines`: highlight evidence for a counter width and accessory fitting.
- `set_coffee_cart`: select a fictional machine, or clear the cart.
- `set_coffee_filter`: add or remove the compatible filter; requires a machine.
- `review_coffee_cart`: open a review for the human. Only the human saves the demo selection.

Manual controls, native WebMCP and the remote MCP connection use the same browser state. These actions never place an order or make a payment. Native WebMCP is optional: the remote connection works in browsers without it.

## Session behavior

Connections expire after 30 minutes, or after the tab stops checking for commands for 45 seconds. A deployment also ends active sessions. Create a new connection when the page reports disconnection.

If an action times out, it may already have run. Inspect the visible state or call `get_coffee_state` before deciding whether to repeat it. The bridge does not replay commands automatically.

## Hosting the demo

This example uses a bounded, in-memory session broker in a single Node process. It is not a general remote-browser proxy. Only the five coffee tools are exposed; client and browser credentials are separate. Tokens, commands and results are never persisted or logged by application code. A multi-replica deployment needs a shared transient broker before scaling this route.

The soundtrack is an AAC stream copy from the existing MP4, served with byte ranges from house S3. `video:render` also extracts it as `demo-audio.m4a`; publishing with `PUBLISH_ASSET=demo-audio.m4a` updates only that object. Playback state and the original Remotion film share their timing and captions.
